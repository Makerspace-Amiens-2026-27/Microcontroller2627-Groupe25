# 2026-11-18 : installation de VS Code et PlatformIO

**Séance :** planifiée · **Durée :** 2 h

## Fait

- Installation de l'extension **PlatformIO IDE** dans VS Code.
- Création d'un premier projet de test (`test blink`) pour la carte
  **Seeed Studio XIAO ESP32S3**, avec le framework Arduino.
- Téléchargement par PlatformIO de la plateforme Espressif 32 et de ses outils
  (compilateurs Xtensa et RISC-V, framework Arduino ESP32).

## Pourquoi

PlatformIO est l'environnement utilisé pour programmer le microcontrôleur du
projet : il gère la carte, le compilateur et les bibliothèques à partir d'un
seul fichier, `platformio.ini`.

Problème rencontré : le téléchargement du core n'est pas allé jusqu'au bout.
Le paquet `framework-arduinoespressif32-esp32s3-libs` est resté incomplet, donc
le projet ne pouvait pas encore compiler.
